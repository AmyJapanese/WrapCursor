# WrapCursor

画面の外端にカーソルを動かすと、反対側へ移動するWindows常駐アプリです。

## 起動と操作

配布フォルダーのWrapCursor.exeを起動してください。タスクバー右下の通知領域（隠れている場合は「∧」）にアイコンが表示されます。
アイコンを右クリックすると「有効」でオン／オフ、「終了」で終了できます。起動直後は有効です。二重起動した場合、後から起動したアプリは終了します。

モニター間の境界は普通に移動できます。左右の折り返しは同じ高さ、上下は同じ横位置を保ちます。高さが違う配置では、その行・列に存在するモニターの外端で折り返します。配置の空白に面した途中の端は通常のWindowsの制限に従います。

## 動作確認

- 左右・上下の端へ動かし、反対側へ一度だけ移動すること。
- 隣接するモニター間は通常どおり移動すること。
- 「有効」を外すと折り返しが止まり、戻すと再開すること。
- モニターの接続や配置変更後も現在の構成で移動すること。
- 二重起動でアイコンが増えず、「終了」でアイコンとプロセスが消えること。
- 起動時の監視失敗では理由が表示され、カーソル移動失敗では無効になり通知されること。

## ソースからビルド

.NET 8 SDKを用意し、build.ps1を実行します。配布成果物はdist/に生成されます。SDKのパスは`-DotnetPath`で指定できます。
`-SelfContained`を指定すると.NETの追加インストールなしで起動できる配布になります。指定しない場合は.NET 8 Desktop Runtimeが必要です。
自動起動登録とインストーラーは初版に含みません。
